## 🎓 About Me & Academic Journey

I am an undergraduate student pursuing **Computer Science with a specialization in Data Science (CS-DS)**. I am passionate about understanding data patterns, building predictive models, and bridging the gap between **data science, machine learning, and scalable software systems**.

As a student, I believe the best way to master computer science is by building real, end-to-end applications—applying theoretical mathematics, statistics, and algorithms directly to practical problems.

### 🔬 What I'm Focused On
- **Data Science & Machine Learning:** Exploratory Data Analysis (EDA), statistical modeling, feature engineering, and predictive pipelines with Scikit-Learn and Python.
- **Data Engineering & Analytics:** High-performance columnar querying with DuckDB, dbt SQL transformations, and Parquet data pipelines.
- **Full-Stack Development:** Building robust web backends with FastAPI and Node.js, coupled with clean, interactive user interfaces in React.
- **Applied Algorithms & Systems:** Implementing core Data Structures & Algorithms (DSA), distributed IoT architectures, and exploring Web3 technologies.

## 🚀 Featured Projects & Academic Builds

A showcase of hands-on data science pipelines, analytical tools, and full-stack software built throughout my studies:

### 1. Data Science & Columnar Analytics

#### 📊 **[Telecom Churn Data Warehouse](https://github.com/SyedAynan/telecom-churn-dw)** &mdash; *Sub-12ms Columnar Analytics & ML Pipeline*
> **Tech:** `DuckDB 1.3.2` &middot; `dbt 1.12.5` &middot; `Python 3.12` &middot; `Scikit-Learn` &middot; `Streamlit` &middot; `Parquet` &middot; `GNU Make` &middot; `uv`
- **Sub-12ms Query Latency:** Columnar analytics engine built on DuckDB, executing aggregations over millions of rows in milliseconds.
- **End-to-End Orchestration:** Automated single-command lifecycle (`make all`): raw ETL &rarr; dbt compilation &rarr; ML training &rarr; batch scoring &rarr; warehouse updates.
- **Data Quality & Testing:** Verified with **43 dbt model test assertions** + **39 pytest unit tests** passing with 100% test coverage.
- **Streaming Telemetry Simulator:** Real-time carrier signal simulator (Jio, Airtel, Vi, BSNL) joined directly with customer risk scoring.
- **Interactive Dashboard:** Responsive Streamlit interface with animated count-up KPI tiles, factor coefficient waterfall breakdowns, and live risk queues.

### 2. Algorithmic Systems & FinTech

#### 🏦 **[Nexus Bank](https://github.com/SyedAynan/Nexus-Bank)** &mdash; *Full-Stack Digital Banking & AML Compliance Platform*
> **Tech:** `FastAPI` &middot; `React 18` &middot; `PostgreSQL` &middot; `Vite` &middot; `Docker` &middot; `WebSockets` &middot; `Python` &middot; `Machine Learning`
- **Fraud Intelligence:** Integrated machine learning fraud detection model alongside Anti-Money Laundering (AML) graph analytics for detecting suspicious transaction rings.
- **DSA Execution Engines:** Built around 7 native Data Structures & Algorithms (DSA) execution engines for transaction scheduling, graph traversals, and ledger reconciliation.
- **Architecture & Security:** Digital banking interface with multi-factor authentication (JWT + MFA) and 5-role Role-Based Access Control (RBAC).
- **Real-Time Telemetry:** Live bidirectional WebSocket stream powering live transaction approvals and audit trails.
- **Containerization:** Multi-stage Docker setup for reproducible local development and deployment parity.

---

### 3. Edge Computing & Healthcare IoT

#### 🏥 **[Patient Monitoring Mesh](https://github.com/SyedAynan/Patient-monitoring-mesh)** &mdash; *Edge-Intelligence Healthcare Mesh Network*
> **Tech:** `Python 3.10+` &middot; `TypeScript` &middot; `FastAPI` &middot; `React / Next.js` &middot; `SQLite` &middot; `HMAC-SHA256` &middot; `Capacitor (Android)`
- **Edge Risk Engine:** Rule-based clinical triage scoring executed locally on edge nodes and identically on the backend to prevent score drift.
- **Store-and-Forward Resilience:** Self-healing routing topology with automatic rerouting to alternate relays during simulated network partitions.
- **Cryptographic Security:** Gateway-level HMAC-SHA256 frame verification ensuring payload integrity.
- **Testing & Verification:** Validated through **249 comprehensive tests** and a 40-session recorded experimental evaluation run.
- **Cross-Platform Client:** Desktop app, installable Progressive Web App (PWA), and Android build via Capacitor.

#### ⚓ **[Master of Chios](https://github.com/SyedAynan/Master-of-Chios)** &mdash; *Aegean Maritime & Economic Simulation Engine*

- **Economic Simulator:** Dynamic supply-and-demand market simulation modeling fluctuating prices for commodities across Mediterranean ports.
