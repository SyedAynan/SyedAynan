## ⚡ Executive Profile & Engineering Overview

I am a **Full Stack, Web3, and Systems Engineer** focused on building production-grade software across distributed backends, columnar data warehouses, real-time IoT architectures, and decentralized protocols.

My engineering ethos emphasizes **sub-second performance**, **bulletproof automated test coverage**, and **clean architectural boundaries** — shipping systems with verifiable reliability from database schema to interactive UI.

### 🏛️ Core Engineering Pillars
- **Enterprise Distributed Platforms:** High-concurrency asynchronous backends with FastAPI and Node.js, role-based access control, cryptographic verification, and live WebSocket telemetry.
- **Data Warehousing & OLAP:** Sub-12ms analytical query pipelines powered by DuckDB, dbt SQL models, automated Parquet batch scoring, and machine learning inference.
- **IoT & Edge Intelligence:** Resilient sensor mesh networks with edge risk evaluation, store-and-forward failover, HMAC-SHA256 packet authentication, and cross-platform mobile telemetry.
- **Web3 & Decentralization:** Smart contracts, token economics, and decentralized primitives spanning Ethereum (Solidity, Hardhat) and Solana ecosystems.
- **Real-Time Graphics & Simulation:** 60 FPS HTML5 Canvas rendering loops and zero-dependency procedural Web Audio API synthesis.

### 2. Data Engineering & OLAP Warehousing

#### 📊 **[Telecom Churn Data Warehouse](https://github.com/SyedAynan/telecom-churn-dw)** &mdash; *Sub-12ms Columnar Analytics & ML Pipeline*
> **Tech:** `DuckDB 1.3.2` &middot; `dbt 1.12.5` &middot; `Python 3.12` &middot; `Scikit-Learn` &middot; `Streamlit` &middot; `Parquet` &middot; `GNU Make` &middot; `uv`
- **Sub-12ms Query Latency:** Columnar analytics engine built on DuckDB, executing aggregations over millions of rows in milliseconds.
- **End-to-End Orchestration:** Automated single-command lifecycle (`make all`): raw ETL &rarr; dbt compilation &rarr; ML training &rarr; batch scoring &rarr; warehouse updates.
- **Rigorous Verification:** **43 dbt model test assertions** + **39 pytest unit tests** passing with 100% green coverage.
- **Streaming Telemetry Simulator:** Real-time carrier signal simulator (Jio, Airtel, Vi, BSNL) joined directly with customer risk scoring.
- **60 FPS Dashboard:** Responsive Streamlit interface with animated count-up KPI tiles, factor coefficient waterfall breakdowns, and live risk queues.

### 3. IoT, Edge Intelligence & MedTech

#### 🏥 **[Patient Monitoring Mesh](https://github.com/SyedAynan/Patient-monitoring-mesh)** &mdash; *Edge-Intelligence Healthcare Mesh Network*
> **Tech:** `Python 3.10+` &middot; `TypeScript` &middot; `FastAPI` &middot; `React / Next.js` &middot; `SQLite` &middot; `HMAC-SHA256` &middot; `Capacitor (Android)`
- **Edge Risk Engine:** Rule-based clinical risk engine executed locally on edge nodes and identically on the backend to eliminate scoring drift.
- **Store-and-Forward Resilience:** Self-healing routing topology with automatic rerouting to alternate relays and bounded buffers during network partitions.
- **Hardware-Agnostic Layering:** Abstracted transport protocol allowing drop-in replacement between simulated links and physical ESP32/ESP-NOW radios.
- **Cryptographic Authentication:** Gateway-level HMAC-SHA256 frame verification ensuring zero unauthenticated payload parsing.
- **249 Passing Tests:** Verified through **249 comprehensive tests** and a 40-session recorded experimental evaluation campaign.
- **Cross-Platform:** One-click launch on desktop, installable Progressive Web App (PWA), and native Android APK build via Capacitor.
